# LaunchLens AI Frontend

This is the React frontend for LaunchLens AI, built with Vite.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Notes

The app uses React Router for navigation and a modern dark UI intended for startup validation workflows.

## Environment

This frontend uses the backend API at the same origin in development. If needed, configure your proxy or API base URL before deployment.

## Production build

```bash
npm run build
```

This creates a production-ready bundle in the `dist/` folder.

## Important

The content generated in the app is meant to support strategic thinking and should be validated with real-world research before making business decisions.
