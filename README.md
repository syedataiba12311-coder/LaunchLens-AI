🚀 LaunchLens AI – Startup Idea Validator

LaunchLens AI is an AI-powered web application that helps entrepreneurs, students, freelancers, and startup founders validate their startup ideas before investing time and money.

Instead of manually researching competitors, business models, and market opportunities, users simply enter their startup idea and receive a comprehensive AI-generated business analysis within seconds.

🌍 Problem Statement

Many aspiring entrepreneurs have innovative ideas but struggle to answer important business questions such as:

- Is my startup idea viable?
- Who are my competitors?
- Who is my target audience?
- How can I generate revenue?
- What should my MVP include?
- How should I market my product?

Conducting this research manually requires significant time and business expertise.

LaunchLens AI automates this process using Artificial Intelligence.

 💡 Solution

LaunchLens AI uses Large Language Models (LLMs) to instantly generate a professional startup validation report, helping founders make informed decisions before building their products.

# 📦 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_GITHUB_REPO.git
```

Go inside the project

```bash
cd LaunchLens-AI
```

---

## Install Frontend

```bash
cd frontend
npm install
```

Run frontend

```bash
npm run dev
```

---

## Install Backend

Open another terminal

```bash
cd backend
npm install
```

Create a `.env` file

```env
GROQ_API_KEY=YOUR_API_KEY
PORT=5000
```

Run backend

```bash
npm run dev
```

---

🚀 Usage

1. Open the application.
2. Enter your startup details.
3. Click **Analyze Startup**.
4. Wait for the AI analysis.
5. View the complete startup validation report.
