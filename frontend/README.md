# LaunchLens AI

LaunchLens AI is an AI-powered web application that helps entrepreneurs, students, freelancers, and startup founders validate startup ideas before investing time and money.

Instead of manually researching competitors, business models, and market opportunities, users can enter a startup idea and receive an AI-generated validation report within seconds.

## Problem statement

Many aspiring entrepreneurs have strong ideas but struggle to answer key business questions such as:

- Is the idea viable?
- Who are the competitors?
- Who is the target user?
- How can revenue be generated?
- What should the MVP include?
- How should the product be marketed?

Doing this research manually takes time and often requires business expertise.

## Solution

LaunchLens AI uses an LLM to generate a structured startup analysis, including executive summaries, SWOT review, risk assessment, market positioning, and roadmap recommendations.

## Installation

Clone the repository:

```bash
git clone https://github.com/syedataiba12311-coder/LaunchLens-AI.git
cd LaunchLens-AI
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

Open a second terminal:

```bash
cd backend
npm install
```

Create a `.env` file with:

```env
GROQ_API_KEY=YOUR_API_KEY
PORT=5000
```

Run the backend:

```bash
npm run dev
```

## Usage

1. Open the application.
2. Enter your startup name, idea, target market, and goals.
3. Click Analyze Startup.
4. Wait for the AI analysis.
5. Review the generated validation report.
6. Validate the recommendations with customer research before building.

## Important note

The output generated by LaunchLens AI is a strategic draft. It should be treated as decision support, not a guarantee of startup success. Always validate assumptions with actual user interviews, market research, and product testing.
